Este documento utiliza um arquivo CSS externo vinculado através da tag <link>

Vantagens do CSS EXterno

  • separaçao completa entre conteudo (html) e design (css)
  • reutulizaçao em multiplas paginas
  • facilita a manutençao do codigo
  • melhor organizaçao do projeto
  • pode ser armazenado mo cache do navegador, melhorando a performance
